# AI Telecom Intelligence Dashboard

An interactive dashboard for telecom revenue analytics, billing, collections, and anomaly detection.

## Live Demo

**[Open AI Telecom Intelligence Dashboard](https://huggingface.co/spaces/chandels/ai-telecom-intelligence)**

## Features

- Revenue and billing KPIs
- Region-wise and service-wise analytics
- Interactive charts and filters
- Anomaly detection and investigation
- CSV export for further analysis

## Technology Stack

- HTML, CSS and JavaScript
- Plotly.js
- PapaParse
- Hugging Face Spaces

## Dataset

The dashboard uses a telecom revenue dataset for analytics and anomaly investigation. Publicly shared data should be synthetic and non-confidential.

## Deployment

The interactive dashboard is hosted on Hugging Face Spaces.
